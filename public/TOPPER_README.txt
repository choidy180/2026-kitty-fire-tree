이 폴더에 topper.png (또는 topper.webp / .gif / .svg / .jpg) 를 넣으면
트리 꼭대기 토퍼가 기본 고양이 대신 그 이미지로 바뀝니다.

- 배경이 투명한 PNG가 가장 깔끔하게 나옵니다.
- 배경이 단색(흰색 등)인 JPG도 테두리 색을 기준으로 배경을 자동으로 지웁니다.
- 개발 서버(npm run dev): 파일을 넣고 새로고침하면 바로 반영
- 프로덕션(npm run build && npm start): 파일을 넣은 뒤 다시 빌드해야 반영
- 실행 중에는 화면 오른쪽 위 IMAGE 버튼이나 드래그앤드롭으로도 바로 바꿀 수 있습니다.
- 사용할 권한이 있는 이미지를 넣어 주세요.
